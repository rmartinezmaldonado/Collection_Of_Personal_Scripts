# warframe-tracking

# What is this
The main idea behind this Bash script is to help me manage my Warframe inventory (blueprints only) rather than use third-party sites like AlecaFrame (sites like these get in trouble with Digital Extremes).

Essentially, I would have a text file that I would dynamically add sets I have and modify their values. Do I have a specific prime set that I haven't registered yet? Using the command line UI I would build into this, I would add the set into this. Do I have a specific prime set that I can sell? The script should essentially tell me yes, I do have it.

# Why does this exist?
Personal helper for checking my inventory in the game Warframe.

I mainly intend to use this as a quick checker of sets that I can trade in game without exiting the trade chat, looking into my inventory, and then coming back to see someone beating me to the punch (I play on console).

# How to get this to work
This should work (when it's ready):
```
warframe_tracker.sh
```
