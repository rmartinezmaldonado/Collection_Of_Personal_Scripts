# file-archiving

# What is this
There are currently two scripts here:

## archiveclasswork
The original Bash script that I've been using. This was mainly responsible for moving files that were in my root directory to the directory that contains all of my CU Boulder classwork.

## archivemanager
This is meant to be a more comprehensive version of `archiveclasswork`

# Why does this exist?
This is purely for convenience as I was extremely annoyed with running `mv (long file paths)` commands everytime I downloaded something from class and especially files from my Linux SysAdmin network.
