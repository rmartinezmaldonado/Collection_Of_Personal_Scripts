# download-organizer

# What is this
This is a Bash script that is designed to organize files within the target directory by their file extensions. The scope of this script is limited exclusively to the files on the directory itself, so it will not look into other subdirectories. This is intended to ensure that other applications or tools you're using don't have their critical components transferred over to the storage folders.

# Why does this exist?
Too much clutter in my Downloads folder

# How to get this to work
As you would run any other Bash script.
